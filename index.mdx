## Temel bilgiler

| | |
|---|---|
| Base URL | `https://api.sarraf.pro` |
| Sürüm öneki | `/v1` |
| Kimlik doğrulama | HTTP Basic — `apiUserId` : `secretKey` |
| Cevap biçimi | `success` / `data` / `meta` zarfı; hatada `error` + `traceId` |

```bash
curl 'https://api.sarraf.pro/v1/customers?pageSize=1' \
  -u 'apiUserId:secretKey'
```
