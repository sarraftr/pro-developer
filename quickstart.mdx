Bu rehber sizi sıfırdan ilk başarılı API cevabına ulaştırır: API anahtarı üretimi, kimlik doğrulama ve ilk `GET` isteği.

## Ön koşullar

- Aktif bir SarrafPro şirket hesabı (Enterprise paketi)
- Şirket panelinde API anahtarı üretme yetkisi

## Başlayın

<Steps>
  <Step title="API anahtarı üretin">
    SarrafPro panelinde **Ayarlar → Geliştirici → API Kullanıcıları** bölümünden yeni bir anahtar oluşturun. Üretimde size bir `apiUserId` ve bir `secretKey` verilir.

    <Warning>
      Anahtarın **geçerlilik tarihi (accessDate)** gelecekte olmalıdır; tarihi gün bazında seçerseniz anahtar gün sonunda (00:00) devre dışı kalır. `secretKey` yalnızca üretim anında gösterilir — güvenli saklayın.
    </Warning>
  </Step>
  <Step title="Authorization başlığını oluşturun">
    SarrafPro Dış API, HTTP Basic kimlik doğrulaması kullanır. Kullanıcı adı `apiUserId`, parola `secretKey` olacak şekilde Base64 kodlayın:

    ```bash
    node -e "console.log(Buffer.from('<apiUserId>:<secretKey>').toString('base64'))"
    ```
  </Step>
  <Step title="İlk isteğinizi atın">
    Cari hesap listesi ucu, API'nin en temel okuma noktasıdır:

    ```bash
    curl 'https://api.sarraf.pro/v1/customers?page=1&pageSize=5' \
      -H 'Authorization: Basic <base64>'
    ```

    Başarılı cevap:

    ```json
    {
      "success": true,
      "data": [
        {
          "id": "6a39d846afed5527f1c85f3b",
          "idNo": "6310669512",
          "nameSurname": "ÖRNEK KUYUMCULUK A.Ş.",
          "idType": "company",
          "isVerify": false
        }
      ],
      "meta": {
        "requestId": "c6c85e42-dd06-4cb3-885b-c0ca551ee866",
        "timestamp": "2026-09-05T00:00:00.000Z",
        "page": 1,
        "limit": 25,
        "total": 114,
        "pages": 5
      }
    }
    ```
  </Step>
  <Step title="Cevap zarfını tanıyın">
    Tüm uçlar aynı zarfı kullanır: başarılı cevapta `success` + `data` + `meta`, hatalı cevapta `success: false` + `error` + `traceId`. Ayrıntılar için [Genel Bakış](/api-reference/genel-bakis) sayfasına bakın.
  </Step>
</Steps>

<Tip>
  Takıldığınız yerde bize yazın: [destek@sarraf.pro](mailto:destek@sarraf.pro). Hata bildirirken cevaptaki `traceId` değerini paylaşmanız yeterlidir.
</Tip>
