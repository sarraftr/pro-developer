Banka hesapları kaynağı, şirketin gerçek banka hesaplarını (`bank=true`; kasa/pos/kredi hesapları hariç) bakiye ve son sorgu bilgisiyle sunar.

## `GET /v1/bank-accounts` — hesap listesi

### Sorgu parametreleri

Ortak parametreler için [Genel Bakış](/api-reference/genel-bakis).

| Parametre | Tür | Açıklama |
|---|---|---|
| `archived` | boolean | Verilmezse yalnız arşivsiz hesaplar döner |
| `currency` | string | Para birimi (büyük harfe normalize edilir) |
| `bankCode` | string | Banka kodu |
| `isApi` | boolean | `true`: yalnız banka entegrasyonu bağlı hesaplar |
| `q` | string | Hesap adında arama |
| `updatedSince` | date-time | Yalnız bu tarihte/sonra güncellenen hesaplar (`updatedAt >=`) |

Sıralama whitelist'i: `createdDate`, `name`, `balance`, `updatedAt`. Varsayılan `createdDate:asc`.

<Note>
  `updatedAt` bakiye/banka senkronu güncellemelerinde de ilerler; incremental senkronizasyonda `updatedSince` + `sort=updatedAt:asc` kullanın. Bakiyenin son sorgu zamanını ayrıca `lastCheckAt` alanı verir.
</Note>

### Cevap alanları (liste öğesi)

| Alan | Anlam |
|---|---|
| `id` | Hesap kimliği |
| `name`, `bankName`, `bankCode`, `code` | Hesap ve banka tanımları |
| `iban`, `currency` | IBAN ve para birimi |
| `type` | `cash`, `bank`, `pos`, `credit` (bu kaynakta her zaman `bank` ağırlıklı) |
| `default` | Varsayılan hesap mı |
| `isApi` | Banka entegrasyonu bağlı mı |
| `isDemo` | Demo hesap mı |
| `limit` | Sorgulama limiti |
| `balance` | Güncel bakiye (son sorgudaki) |
| `lastCheckAt` | Son banka sorgusu zamanı |
| `lastTransactionAt` | Son çekilen hareketin zamanı |
| `lastCheckStatus` / `lastCheckMessage` | Son sorgunun başarı durumu ve banka cevabı |
| `lastCheckSize` | Son sorguda çekilen hareket sayısı |
| `updatedAt` | Son güncelleme zamanı (bakiye/senkron güncellemesi de ilerletir) |

## `GET /v1/bank-accounts/{id}` — hesap detayı

Liste alanlarına ek olarak:

| Alan | Anlam |
|---|---|
| `subAccounts` | Alt hesaplar (kendi bakiye bilgileriyle) |
| `expiryDay` | POS ise bloke, kredi ise son ödeme günü |
| `commission` | POS komisyon tutarı |
| `archived` | Arşiv durumu |

<Warning>
  Banka entegrasyon kimlik bilgileri (`integrationsData`) ve iç kilit alanları hiçbir uçta dönmez.
</Warning>

<Tip>
  Bakiyeleri tazelemek için [Banka sorgusu tetikleme](/api-reference/banka-sorgu-tetikleme) ucunu kullanın; ardından hesap listesini yeniden okuyun.
</Tip>
