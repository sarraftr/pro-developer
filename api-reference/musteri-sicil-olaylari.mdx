Sicil olayları, müşteriler hakkında kaydedilen risk değerlendirme kayıtlarıdır (şüphe durumları). Kayıt seviyeleri müşterinin `recordLevel` alanıyla aynı ölçeği kullanır.

## `GET /v1/customers/events` — olay listesi

Varsayılan sıralama **en yeni olay önce** (`eventDate:desc`).

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/events?idNo=1976926558&pageSize=25' \
  -u 'apiUserId:secretKey'
```

### Sorgu parametreleri

| Parametre | Tür | Açıklama |
|---|---|---|
| `idNo` | string | Müşteri TCKN/VKN tam eşleşme |
| `recordLevel` | integer | `0` kayıt yok, `1` normal, `2` güvenli, `3` riskli, `4` yasaklı |
| `startDate` / `endDate` | date-time | `eventDate` aralığı |
| `updatedSince` | date-time | Artımlı senkronizasyon |

### Cevap alanları

| Alan | Anlam |
|---|---|
| `id` | Olay kayıt kimliği |
| `eventDate` | Olay zamanı |
| `customerId` | İlgili müşteri kimliği — [Müşteri detayı](/api-reference/musteriler) ile çapraz sorgulanabilir |
| `idNo` | Müşteri TCKN/VKN |
| `recordLevel` | Risk seviyesi (0-4) |
| `comment` | Olay açıklaması |

## `GET /v1/customers/events/{id}` — olay detayı

Tek olay kaydını aynı alanlarla döner.

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/events/6a90bb11da99cd3fa911aa02' \
```
