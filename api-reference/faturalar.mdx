Faturalar kaynağı, SarrafPro üzerinden kesilen e-faturaların kayıtlarını sunar. Liste ucu hafif özet döner; kalem satırları (`lines`) ve tam müşteri bloğu detay ucundadır.

## `GET /v1/invoices` — fatura listesi

### Sorgu parametreleri

Ortak parametreler için [Genel Bakış](/api-reference/genel-bakis).

| Parametre | Tür | Açıklama |
|---|---|---|
| `filter[idNo]` | string | Müşteri TCKN/VKN tam eşleşme |
| `filter[invoiceNumber]` | string | Fatura numarası tam eşleşme |
| `filter[type]` | string | Fatura türü |
| `filter[integrator]` | string | Entegratör (Nilvera, GIB vb.) |
| `filter[module]` | string | Faturanın üretildiği modül |
| `filter[startDate]` / `filter[endDate]` | date-time | `transactionDate` (fatura/resmileştirme tarihi) aralığı |
| `filter[updatedSince]` | date-time | Artımlı senkronizasyon |

Sıralama whitelist'i: `transactionDate`, `createdAt`, `updatedAt`, `payableTotal`. Varsayılan `transactionDate:asc`.

### Cevap alanları (liste öğesi)

| Alan | Anlam |
|---|---|
| `id` | Fatura kayıt kimliği |
| `transactionDate` | Fatura / resmileştirme tarihi |
| `invoiceNumber` | Fatura numarası |
| `invoiceType` / `integrator` / `invoiceStatus` | Tür, entegratör ve gönderim durumu |
| `linesTotal`, `kdvTotal`, `allowanceTotal`, `payableTotal` | Tutar özeti (kalem toplamı, KDV, iskonto, ödenecek) |
| `customer` | `{ taxNumber, name }` — müşteri özeti |
| `idNo` | Müşteri TCKN/VKN |
| `module` | Üretildiği modül |

## `GET /v1/invoices/{id}` — fatura detayı

Liste alanlarına ek olarak:

- **`customer`** — tam blok: `taxNumber`, `name`, `taxOffice`, `address`, `district`, `city`, `phone`, `mail`, `webSite`, `country`
- **`invoiceInfo`** — tam entegratör bilgisi: `integrator`, `type`, `uuid`, `invoiceNumber`, `status`
- **`lines[]`** — kalem satırları:

| Kalem alanı | Anlam |
|---|---|
| `name`, `quantity`, `unitType`, `stockCode` | Ürün/hizmet tanımı, miktar, birim, stok kodu |
| `price`, `amount`, `lineTotal` | Birim fiyat, net tutar (KDV ve iskontosuz), satır toplamı |
| `kdvPercent`, `kdvTotal` | KDV oranı ve tutarı |
| `allowancePrice`, `allowanceTotal` | İskonto birim ve toplam tutarı |
| `ozelMatrahTotal` | Özel matrah tutarı |
| `isExtra`, `isDefault`, `isLabor` | Ek kalem / varsayılan kalem / işçilik kalemi |

<Note>
  Fatura modelinde para birimi alanı tutulmaz; tutarlar kayıtlı haliyle döner. Fatura PDF/görsel içeriği bu sürümde API'de yoktur.
</Note>

## `POST /v1/invoices` — fatura oluşturma

Banka hareketinden veya manuel olarak fatura oluşturur. Şirketinizin entegratör (e-fatura) ayarları ve kalem şablonları (variables) kullanılır; e-arşiv/e-fatura yönlendirmesi müşterinin VKN/TCKN kaydına göre otomatik yapılır.

### İstek gövdesi

Banka hareketinden:

```json
{
  "data": {
    "source": { "type": "bank-transaction", "bankTransactionId": "6a42a5a5afed5527f1074a31" },
    "variables": { "id": "6a2f1b989691a108a13ad1ef" },
    "isDraft": true
  }
}
```

Manuel:

```json
{
  "data": {
    "source": { "type": "manual" },
    "customer": { "idNo": "12345678901", "nameSurname": "ÖRNEK KİŞİ", "iban": "TR..." },
    "amount": 125000,
    "description": "Manuel fatura notu",
    "isDraft": true
  }
}
```

| Alan | Tür | Kural |
|---|---|---|
| `source.type` | string | `bank-transaction` veya `manual` (zorunlu) |
| `source.bankTransactionId` | string | `bank-transaction` türünde zorunlu; hareket şirketinize ait olmalı |
| `customer` | object | `manual` türünde zorunlu (`idNo`, `nameSurname`, `iban`); `bank-transaction` türünde hareketteki müşteriyi ezmek için opsiyonel |
| `amount` | number | `manual` türünde zorunlu, pozitif |
| `variables` | object | Kalem şablonu: yalnızca `id` **veya** `key` — [şablon listesi](#get-v1invoice-variables-—-kalem-şablonları) |
| `isDraft` | boolean | `true`: entegratörde **taslak** oluşur; envanter, hareket güncellemesi ve cari upsert yapılmaz |
| `currency` / `exchangeRate` | string / number | Varsayılan `TRY`; başka para biriminde `exchangeRate` zorunlu |
| `description` / `transactionDate` | string | Fatura notu / fatura tarihi (ISO-8601) |

### Cevap — `201`

```json
{
  "success": true,
  "data": {
    "uuid": "0075cc68-e90b-49c2-8434-0d5f779c72bf",
    "invoiceNumber": "BAC2026000006543",
    "invoiceType": "earchive",
    "isDraft": true,
    "customerTaxNumber": "12345678901",
    "source": { "type": "manual", "bankTransactionId": null }
  },
  "meta": { "requestId": "...", "timestamp": "..." }
}
```

<Warning>
  `isDraft: false` ile oluşturma **gerçek** fatura gönderir ve şu yan etkileri üretir: cari kayıt eşleştirme/oluşturma, envanter fişi ve (banka hareketi kaynaklıysa) hareketin `faturalandı` olarak işaretlenmesi. Zaten faturalanmış hareket `409 CONFLICT` döner. Entegratör hataları `502 UPSTREAM_ERROR` döner.
</Warning>

## `GET /v1/invoice-variables` — kalem şablonları

Şirketinizin fatura kalem şablonları (ayar/saflık/işçilik tanımları). `POST /v1/invoices` içindeki `variables.id` seçimini bu listeden yapın; `isDefault: true` olan şablon seçim yapılmadığında kullanılır.

### Sorgu parametreleri

| Parametre | Tür | Açıklama |
|---|---|---|
| `filter[statusType]` | string | `all`, `invoice`, `expense`, `passive` (varsayılan listede pasifler dönmez) |
| `filter[material]` | string | `gold`, `silver`, `platin`, `paladyum`, `usd`, `eur`, `try` |
| `filter[isDefault]` | boolean | Varsayılan şablon |
| `q` | string | Kalem adında arama |

### Cevap alanları

`id`, `key`, `title`, `lineName`, `material`, `statusType`, `type`, `exchange` (saflık), `vatRate`, `unitType`, `laborDisabled`, `laborName`, `laborType`, `stockCode`, `isDefault`, `isManual`, `order`, `words`, `createdAt`, `updatedAt`
