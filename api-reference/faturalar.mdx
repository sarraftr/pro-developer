Faturalar kaynağı, SarrafPro üzerinden kesilen e-faturaların kayıtlarını sunar. Liste ucu hafif özet döner; kalem satırları (`lines`) ve tam müşteri bloğu detay ucundadır.

## `GET /v1/invoices` — fatura listesi

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/invoices?startDate=2026-09-01T00:00:00.000Z&pageSize=25' \
  -u 'apiUserId:secretKey'
```

### Sorgu parametreleri

Ortak parametreler için [Genel Bakış](/api-reference/genel-bakis).

| Parametre | Tür | Açıklama |
|---|---|---|
| `idNo` | string | Müşteri TCKN/VKN tam eşleşme |
| `invoiceNumber` | string | Fatura numarası tam eşleşme |
| `type` | string | Belge türü: `earchive` (e-arşiv) veya `einvoice` (e-fatura) |
| `startDate` / `endDate` | date-time | `transactionDate` (fatura/resmileştirme tarihi) aralığı |

Sıralama whitelist'i: `transactionDate`, `payableTotal`. Varsayılan `transactionDate:asc`.

### Cevap alanları (liste öğesi)

| Alan | Anlam |
|---|---|
| `id` | Fatura kayıt kimliği |
| `transactionDate` | Fatura / resmileştirme tarihi |
| `invoiceNumber` | Fatura numarası |
| `invoiceType` | Belge türü: `earchive` veya `einvoice` |
| `invoiceStatus` | Gönderim durumu |
| `linesTotal`, `kdvTotal`, `allowanceTotal`, `payableTotal` | Tutar özeti (kalem toplamı, KDV, iskonto, ödenecek) |
| `customer` | `{ taxNumber, name }` — müşteri özeti |
| `idNo` | Müşteri TCKN/VKN |

## `GET /v1/invoices/{id}` — fatura detayı

Liste alanlarına ek olarak:

- **`customer`** — tam blok: `taxNumber`, `name`, `taxOffice`, `address`, `district`, `city`, `phone`, `mail`, `webSite`, `country`
- **`invoiceInfo`** — belge bilgisi: `type`, `uuid` (ETTN), `invoiceNumber`, `status`
- **`pdfUrl`** — faturanın PDF görüntüleme bağlantısı; belge kaynağı uygun değilse `null`
- **`lines[]`** — kalem satırları:

| Kalem alanı | Anlam |
|---|---|
| `name`, `quantity`, `unitType`, `stockCode` | Ürün/hizmet tanımı, miktar, birim, stok kodu |
| `price`, `amount`, `lineTotal` | Birim fiyat, net tutar (KDV ve iskontosuz), satır toplamı |
| `kdvPercent`, `kdvTotal` | KDV oranı ve tutarı |
| `allowancePrice`, `allowanceTotal` | İskonto birim ve toplam tutarı |
| `ozelMatrahTotal` | Özel matrah tutarı |
| `isExtra`, `isDefault`, `isLabor` | Ek kalem / varsayılan kalem / işçilik kalemi |

<Note>
  Fatura modelinde para birimi alanı tutulmaz; tutarlar kayıtlı haliyle döner.
</Note>

<Note>
  `pdfUrl` doğrudan açılabilen bir görüntüleme bağlantısıdır; API'den ayrıca dosya indirmeniz gerekmez. Bağlantı yalnız detay ve fatura oluşturma cevaplarında döner, liste ucunda yer almaz.
</Note>

<Note>
  Fatura oluşturma, gönderim ve taslak iptali için [Fatura işlemleri](/api-reference/fatura-olusturma) sayfasına bakın. API üzerinden kesilen faturalar da bu uçlarda görünür.
</Note>

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/invoices/6aae937b8d76c7a547248699' \
  -u 'apiUserId:secretKey'
```
