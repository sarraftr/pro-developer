---
title: "Müşteri değişiklik denetimi"
description: "Müşteri kayıtlarındaki önemli değişikliklerin denetim geçmişi"
---

Müşteri kayıtlarındaki önemli değişiklikler (güncelleme / kaldırma) denetim amacıyla kayıt altına alınır. Bu kaynak, kim-ne-zaman-değişti bilgisini ve değişiklik anlık görüntüsünü sunar.

## `GET /v1/customers/histories` — denetim listesi

Varsayılan sıralama **en yeni önce** (`createdAt:desc`).

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/histories?customerId=6a9c7e2bf2fb39feccb3480b&pageSize=25' \
  -u 'apiUserId:secretKey'
```

### Sorgu parametreleri

| Parametre | Tür | Açıklama |
|---|---|---|
| `customerId` | string | Müşteri kayıt kimliği (ObjectId) |
| `type` | string | `update` veya `remove` |
| `startDate` / `endDate` | date-time | `createdAt` aralığı |
| `updatedSince` | date-time | Artımlı senkronizasyon |

### Cevap alanları (liste öğesi)

`id`, `customerId`, `type`, `createdAt`, `updatedAt`

### Cevap — `200`

```json
{
  "success": true,
  "data": [
    {
      "id": "6a93cd22da99cd3fa911bb31",
      "customerId": "6a9c7e2bf2fb39feccb3480b",
      "type": "update",

      "updatedAt": "2026-08-02T10:12:00.000Z"
    }
  ],
  "meta": {
    "requestId": "c6c85e42-dd06-4cb3-885b-c0ca551ee866",
    "timestamp": "2026-09-20T09:00:00.000Z",

    "total": 114,
    "pages": 5
  }
}
```

## `GET /v1/customers/histories/{id}` — kayıt detayı

Liste alanlarına ek olarak **`data`** döner: değişiklik anındaki kayıt anlık görüntüsü (önceki değerler).

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/histories/6a93cd22da99cd3fa911bb31' \
  -u 'apiUserId:secretKey'
```

### Cevap — `200`

```json
{
  "success": true,
  "data": {
    "id": "6a93cd22da99cd3fa911bb31",
    "customerId": "6a9c7e2bf2fb39feccb3480b",
    "type": "update",
    "createdAt": "2026-08-02T10:12:00.000Z",
    "updatedAt": "2026-08-02T10:12:00.000Z",
    "data": {
      "phone": "5009998877",
      "email": "eski@example.com"
    }
  },
  "meta": {
    "requestId": "c6c85e42-dd06-4cb3-885b-c0ca551ee866",
    "timestamp": "2026-09-20T09:00:00.000Z"
  }
}
```
