Kimlik belge kayıtları, müşterilere ait yüklenmiş belgelerin (kimlik ön/arka, imza, ikametgâh, vergi levhası vb.) doğrulama durumunu izler. Belge **içeriği** API'de dönmez; kayıt ve doğrulama durumu döner.

## `GET /v1/customers/identity-documents` — belge listesi

### Sorgu parametreleri

Ortak parametreler için [Genel Bakış](/api-reference/genel-bakis).

| Parametre | Tür | Açıklama |
|---|---|---|
| `idNo` | string | Belge sahibi TCKN/VKN |
| `type` | string | `front`, `rear`, `accord`, `signature`, `addressDoc`, `activeDoc`, `registryDoc`, `taxDoc`, `signDoc` |
| `channel` | string | Yükleme kanalı: `manual`, `whatsapp`, `idv`, `accord` |
| `idCheck` | boolean | NVİ kimlik doğrulaması geçti mi |
| `isApproval` | boolean | idNo doğrulaması yapıldı mı |
| `isDisabled` | boolean | Verilmezse yalnız **geçerli** belgeler döner |
| `startDate` / `endDate` | date-time | `createdAt` aralığı |
| `updatedSince` | date-time | Artımlı senkronizasyon |

Sıralama whitelist'i: `createdAt`, `updatedAt`, `validityDate`. Varsayılan `createdAt:asc`.

### Cevap alanları (liste öğesi)

| Alan | Anlam |
|---|---|
| `id` | Belge kayıt kimliği |
| `idNo` | Belge sahibi TCKN/VKN |
| `type` | Belge türü |
| `channel` | Yükleme kanalı |
| `fileType` | Dosya türü |
| `validityDate` | Belge geçerlilik tarihi |
| `idCheck` | NVİ doğrulaması geçti mi |
| `isApproval` | idNo doğrulaması yapıldı mı |
| `isDisabled` | Belge geçersiz mi |

## `GET /v1/customers/identity-documents/{id}` — belge detayı

Liste alanlarına ek olarak `description` ve **`data`** (OCR / doğrulama çıkarım sonucu) döner.

<Warning>
  Görsel referansları (`imageUrl`, `imageId` vb.) ve AI ham çıktıları hiçbir uçta dönmez. Belge içeriği indirme ucu bu sürümde yoktur.
</Warning>

## `POST /v1/customers/identity-documents` — belge görseli yükleme

Müşteri tanı (accord) akışı için kimlik veya pasaport görseli yükler. Görsel, belge servisine güvenle taşınır ve belge kaydı oluşur.

### İstek gövdesi

```json
{
  "data": {
    "idNo": "1976926558",
    "type": "front",
    "fileName": "kimlik-on.png",
    "mimeType": "image/png",
    "content": "iVBORw0KGgo...",
    "verificationId": "6a9c7e2bf2fb39feccb3480b"
  }
}
```

| Alan | Tür | Kural |
|---|---|---|
| `idNo` | string | **Zorunlu** — belge sahibi TCKN/VKN/pasaport no |
| `type` | string | **Zorunlu** — `front` veya `rear` (pasaport için yalnız `front` yeterlidir) |
| `fileName` | string | **Zorunlu** |
| `mimeType` | string | `image/jpeg` veya `image/png` |
| `content` | string | **Zorunlu** — base64 görsel içeriği, en fazla 8 MiB |
| `verificationId` | string | Opsiyonel — kaydın ilişkilendirileceği müşteri tanı formu; şirketinize ait olmalı |

### Cevap — `201`

Yalnız belge metası döner; görsel içerik veya görsel adresi (`imageUrl`) **hiçbir zaman** dönmez:

```json
{
  "success": true,
  "data": {
    "id": "6aa6aaf0da99cd3fa911edc7",
    "idNo": "1976926558",
    "type": "front",
    "channel": "accord",
    "fileName": "kimlik-on.png",
    "mimeType": "image/png",
    "createdAt": "2026-09-13T12:00:00.000Z",
    "updatedAt": "2026-09-13T12:00:00.000Z"
  },
  "meta": { "requestId": "...", "timestamp": "..." }
}
```

| Hata | HTTP | Açıklama |
|---|---|---|
| Zorunlu alan eksik / tür hatası / boyut aşımı | 400 | `VALIDATION_FAILED` |
| `verificationId` bulunamadı | 404 | `RESOURCE_NOT_FOUND` |
| Belge yükleme servisi hatası | 502 | `UPSTREAM_ERROR` |
