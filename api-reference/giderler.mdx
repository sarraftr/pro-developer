Giderler kaynağı, şirketinizin gider pusulası kayıtlarını sunar. Oluşturma ve kesinleştirme için [Gider pusulası işlemleri](/api-reference/gider-pusulasi-olusturma) sayfasına bakın.

## `GET /v1/expenses` — gider listesi

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/expenses?startDate=2026-09-01T00:00:00.000Z&pageSize=25' \
  -u 'apiUserId:secretKey'
```

### Sorgu parametreleri

Ortak parametreler için [Genel Bakış](/api-reference/genel-bakis).

| Parametre | Tür | Açıklama |
|---|---|---|
| `idNo` | string | Müşteri TCKN/VKN tam eşleşme |
| `serial` / `number` | string | Belge seri / numarası |
| `bankCode` | string | Banka kodu |
| `isCheck` | boolean | Mahsup/pusula durumu |
| `isExcel` | boolean | Excel ile yüklenenler |
| `formalized` | boolean | `true`: yalnız resmileşmiş (`printStamp` olan) kayıtlar |
| `startDate` / `endDate` | date-time | `transactionDate` aralığı |
| `updatedSince` | date-time | Artımlı senkronizasyon |
| `q` | string | Numerikse `idNo`, metinse ünvan araması |

Sıralama whitelist'i: `transactionDate`, `createdAt`, `updatedAt`, `amount`. Varsayılan `transactionDate:asc`.

### Cevap alanları (liste öğesi)

`id`, `stamp`, `serial`, `number`, `transactionDate`, `amount`, `exchanges`, `quantity`, `unitName`, `attribute` (mahiyet), `idNo`, `nameSurname`, `bankName`, `bankCode`, `isCheck`, `isExcel`, `printStamp`, `printDate`, `createdDate`, `updatedAt`

## `GET /v1/expenses/{id}` — gider detayı

Liste alanlarına ek olarak:

| Alan | Anlam |
|---|---|
| `description`, `address` | Açıklama ve adres |
| `customerInfo` | Müşteri bilgi bloğu |
| `lines[]` | Kalem satırları: `quantity`, `attribute`, `unitName`, `price`, `amount`, `description`, `stockCode`, `stamp`, `bankCode` |
| `invoiceNo` | Takas ise ilgili fatura numaraları |
| `isSwap`, `vSchema`, `currentCode` | Takas ve şema bilgileri |
| `bankTransactionId` | İlgili banka hareketi — [Banka hareketi detayı](/api-reference/banka-hareketleri) ile çapraz sorgulanabilir |

<Note>
  Gider pusulası oluşturma, kesinleştirme ve taslak iptali için [Gider pusulası işlemleri](/api-reference/gider-pusulasi-olusturma) sayfasına bakın. API üzerinden oluşturulan pusulalar da bu uçlarda görünür.
</Note>

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/expenses/6aae79498d76c7a5471ede43' \
  -u 'apiUserId:secretKey'
```
