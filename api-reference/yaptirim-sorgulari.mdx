Yaptırım sorguları kaynağı iki yönlüdür: **tam kapsamlı sorgu tetikleme** (yazma) ve **birleşik sorgu geçmişi** (okuma). Panelde yapılan aramalar ve API'den tetiklenen sorgular aynı geçmişe düşer.

## `POST /v1/customers/sanction-checks` — sorgu tetikleme

Verilen kriterlere göre MASAK, wanted ve PEP listelerinde sorgu çalıştırır; ayrıca şirketinizin müşteri kaydı ve müşteri sicil olaylarıyla eşleştirir. Sonuç log kaydı olarak yazılır.

### Örnek istek

```bash
curl -X POST 'https://api.sarraf.pro/v1/customers/sanction-checks' \
  -u 'apiUserId:secretKey' \
  -H 'Content-Type: application/json' \
  -d '{"data": {"idNo": "1976926558", "fullName": "ÖRNEK MÜŞTERİ"}}'
```

### İstek gövdesi

```json
{
  "data": {
    "idNo": "1976926558",
    "fullName": "ÖRNEK KİŞİ",
    "surname": "ÖRNEK",
    "options": { "wantedQuery": true, "pepQuery": true }
  }
}
```

| Alan | Tür | Kural |
|---|---|---|
| `data.idNo` | string | `idNo`, `fullName` veya `surname`'den **en az biri** zorunlu |
| `data.fullName` | string | Ad bazlı sorgular (masak/wanted/pep) |
| `data.surname` | string | Soyad bazlı daraltma (wanted/pep) |
| `data.options.wantedQuery` | boolean | Varsayılan `true` |
| `data.options.pepQuery` | boolean | Varsayılan `true` |

### Cevap — `201`

```json
{
  "success": true,
  "data": {
    "id": "6a9c930093ea09f8ee9d115c",
    "query": { "idNo": "1976926558", "fullName": "ÖRNEK KİŞİ", "surname": null, "options": { "wantedQuery": true, "pepQuery": true } },
    "summary": { "masakCount": 0, "wantedCount": 0, "pepCount": 0, "hasCustomer": true, "customerEventCount": 0 },
    "matches": { "masak": [], "wanted": [], "pep": [] },
    "checkedAt": "2026-09-05T23:59:00.000Z"
  },
  "meta": { "requestId": "...", "timestamp": "..." }
}
```

| Alan | Anlam |
|---|---|
| `summary.masakCount` / `wantedCount` / `pepCount` | Liste eşleşme sayıları |
| `summary.hasCustomer` | Şirket müşteri kaydında eşleşme var mı |
| `summary.customerEventCount` | Müşterinin sicil olayı sayısı |
| `matches` | Liste eşleşme içerikleri (tam kayıtlar) |

<Note>
  Sorgu kaydına `userId` olarak tetikleyen API kullanıcısının kimliği yazılır; IP ve user-agent denetim amacıyla saklanır.
</Note>

## `GET /v1/customers/sanction-checks` — birleşik sorgu geçmişi

Panel aramaları ve API sorgularının birleşik geçmişi. Varsayılan sıralama **en yeni önce** (`createdAt:desc`).

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/sanction-checks?idNo=1976926558&pageSize=25' \
  -u 'apiUserId:secretKey'
```

### Sorgu parametreleri

| Parametre | Tür | Açıklama |
|---|---|---|
| `idNo` | string | Sorgulanan TCKN/VKN |
| `fullName` | string | Sorgulanan ad soyad |
| `startDate` / `endDate` | date-time | `createdAt` aralığı |
| `updatedSince` | date-time | Artımlı senkronizasyon |

### Cevap alanları (liste öğesi)

`id`, `idNo`, `fullName`, `surname`, `summary` (eşleşme sayıları), `createdAt`, `updatedAt`

### Cevap — `200`

```json
{
  "success": true,
  "data": [
    {
      "id": "6aa2ff31da99cd3fa911ee55",
      "idNo": "1976926558",
      "fullName": "ÖRNEK MÜŞTERİ",
      "surname": null,
      "summary": {
        "masak": 0,
        "wanted": 0,
        "pep": 0,
        "isError": false
      },
      "createdAt": "2026-09-16T09:30:00.000Z",
      "updatedAt": "2026-09-16T09:30:00.000Z"
    }
  ],
  "meta": {
    "requestId": "c6c85e42-dd06-4cb3-885b-c0ca551ee866",
    "timestamp": "2026-09-20T09:00:00.000Z",

    "total": 114,

}
```

## `GET /v1/customers/sanction-checks/{id}` — sorgu detayı

Liste alanlarına ek olarak: `query` (tam kriter), `matches` (tam liste içerikleri), `customer` (eşleşen müşteri kaydı), `customerEvents` (müşteri sicil olayları), `checkedAt`.

<Tip>
  Banka hareketleri için [gömülü `masak` bölümü](/api-reference/banka-hareketleri), müşteri bazlı sicil için [Müşteri sicil olayları](/api-reference/musteri-sicil-olaylari) kaynağını da kullanabilirsiniz.
</Tip>

### Örnek istek

```bash
curl 'https://api.sarraf.pro/v1/customers/sanction-checks/6aa2ff31da99cd3fa911ee55' \
  -u 'apiUserId:secretKey'
```
